# Contributing

Yuva is pre-alpha. The design is in [docs/architecture.md](docs/architecture.md) and the work is
in [docs/roadmap.md](docs/roadmap.md) and the GitHub issues.

- Open an issue before a large change, so we can agree on the approach first.
- Your first pull request asks you to sign the [CLA](CLA.md) by posting a comment. It lets the
  project stay open source while also offering a commercial license and a hosted service; you keep
  the copyright to your work.
- Code, identifiers, commit messages and user-facing strings are in English. Translations go
  through the Lingui catalogs.
- Commit subjects follow Conventional Commits (`feat:`, `fix:`, `docs:`, …).
- Every part has a check command (see `CLAUDE.md`). It must pass before review.
- Code you add under `sdk/` or `openapi/` is MIT; everywhere else AGPL-3.0. See
  [LICENSING.md](LICENSING.md).
