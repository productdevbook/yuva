## summarize(text, options?)

Returns `{ summary, tokens }`.

| Option | Meaning |
|---|---|
| `length` | `short`, `medium` or `long`. Defaults to `short`. |
| `language` | The summary's language as a BCP 47 tag. Defaults to the text's. |

## usage()

Returns the requests and tokens used this month: `{ requests, tokens, limit }`.

## Errors

Every method throws an `AcmeError` with `status` and `code`; `429 rate_limited` carries
`retryAfter` in seconds.
