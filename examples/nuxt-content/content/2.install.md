---
title: Install
description: Add the Acme client to a Node or browser project.
---

The client runs on Node 22 or later and in current browsers.

```sh
npm install acme
```

## Configure

| Option | Meaning |
|---|---|
| `apiKey` | Your API key. Required. |
| `baseUrl` | The API's address. Defaults to Acme's. |
| `timeout` | Milliseconds before a request fails. Defaults to `10000`. |

Keep the API key on your server; in a browser, call your own backend instead.
